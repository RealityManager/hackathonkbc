# KBC Relève associative — PoC hackathon

Prototype de **continuité de mandat** pour un compte associatif (troupe scoute).

## Lancer

```bash
cd backend && npm start
cd frontend && npx vite
```

UI : http://localhost:5173  
Clique **Reset démo** avant de filmer.

## Scénario

Alice (bannière septembre) → Itsme → Bob (notif) → Itsme → dashboard héritage.
